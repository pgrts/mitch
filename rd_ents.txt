<p><code>tf_logic_robot_destruction</code>  is a   <a href="/wiki/Point_entity" title="Point entity">point entity</a>  <a href="/wiki/Entity_availability_overview" title="Entity availability overview">available</a> in <span style="white-space:nowrap; background:rgb(0,0,0,.16); font-weight:bold; padding:2px; border-radius:4px"><span style="user-select:none; position:relative; bottom:.1em"><a href="/wiki/Team_Fortress_2" title="Team Fortress 2"><img alt="Team Fortress 2" src="/w/images/thumb/8/84/Tf2-16px.png/16px-Tf2-16px.png" decoding="async" width="16" height="16" srcset="/w/images/thumb/8/84/Tf2-16px.png/24px-Tf2-16px.png 1.5x, /w/images/thumb/8/84/Tf2-16px.png/32px-Tf2-16px.png 2x" data-file-width="256" data-file-height="256" /></a></span> <a href="/wiki/Team_Fortress_2" title="Team Fortress 2"><span title="Team Fortress 2" style="color:#CF7336;">Team Fortress 2</span></a></span>.
</p><p>The master control entity for the robot destruction game mode. It is the base entity used by <a href="/wiki/Tf_logic_player_destruction" title="Tf logic player destruction">Tf logic player destruction</a>.
</p>

<p><code>item_bonuspack</code>  is a   <a href="/wiki/Model_entity" title="Model entity">model entity</a>  <a href="/wiki/Entity_availability_overview" title="Entity availability overview">available</a> in <span style="white-space:nowrap; background:rgb(0,0,0,.16); font-weight:bold; padding:2px; border-radius:4px"><span style="user-select:none; position:relative; bottom:.1em"><a href="/wiki/Team_Fortress_2" title="Team Fortress 2"><img alt="Team Fortress 2" src="/w/images/thumb/8/84/Tf2-16px.png/16px-Tf2-16px.png" decoding="async" width="16" height="16" srcset="/w/images/thumb/8/84/Tf2-16px.png/24px-Tf2-16px.png 1.5x, /w/images/thumb/8/84/Tf2-16px.png/32px-Tf2-16px.png 2x" data-file-width="256" data-file-height="256" /></a></span> <a href="/wiki/Team_Fortress_2" title="Team Fortress 2"><span title="Team Fortress 2" style="color:#CF7336;">Team Fortress 2</span></a></span>. It is the power core that the players collect in Robot Destruction. It adds one point to the team that picks it up and restores 5 HP (into overheal) and 5 ammo (flat amount).
</p>
